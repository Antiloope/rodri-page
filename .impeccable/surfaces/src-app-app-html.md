# Surface: Artist home

## Scope and mode
Experience. Artist home inside the Spotify shell: hero, Popular, Contact, shelves, about.

## Audience / job
A visitor should leave remembering “Rodrigo Pizarro” and that his CV is a Spotify artist page. Recruiters and peers both arrive; exploration leads.

## Action
Play starts Popular. Follow opens LinkedIn. Share shares this page. EN/ES sits in the top bar.

## Constraints
Keep current copy, links, and photos. No invented jobs. No Spotify wordmark. Static GitHub Pages. Docker toolchain.

## Direction
Canon Spotify artist page. Desktop = sidebar + full-bleed hero + Popular/Contact + shelves + dock. Mobile = same grammar collapsed. Home topbar overlays the hero: transparent at rest, solidifies to pane on scroll. Detail routes keep a solid pane topbar in flow.

## Memorable moment
The name at display scale on the real photo, unobstructed by a black header strip, then a green Play that starts Popular.
